# Gym Tracker V4.3

A mobile-first, offline-capable hypertrophy training PWA.

## V4.3
- Redesigned workout-first UI; visual exercise cards instead of form-heavy layouts
- Automatic previous-session carry-over
- Beat-last-session progression targets
- Rep-range progression and load-increase suggestions
- RIR targets
- Estimated 1RM
- Load/strength PR detection
- Exercise detail/history modal
- Exercise notes
- Workout volume calculation
- Session history with PRs and volume
- Bodyweight trend and muscle-focus dashboard
- JSON export/import
- Local-first data with V3/V2/V1 migration
- Offline PWA support

## Run
Open the folder in VS Code and use Live Server. GitHub Pages also works because the app is static.

## Data
Stored locally in `gymTrackerV43`. Existing V3/V2/V1 local data is migrated automatically on first launch.
